# Sales Data Analysis Dashboard

## About Project
This project is a Python-based Sales Data Analysis Dashboard.
It uses Pandas and Matplotlib to analyze sales data and create charts.

## Features
- Load sales data from CSV files
- Clean and process data
- Calculate total and average sales
- Analyze product-wise sales
- Analyze monthly sales
- Create data visualization charts
- Generate sales reports

## Technologies Used
- Python
- Pandas
- Matplotlib
- CSV

## Project Structure
- data/raw/ - Raw sales dataset
- data/processed/ - Processed data
- data/reports/ - Generated reports
- notebooks/ - Analysis notebooks
- sales_analyzer/ - Python modules
- main.py - Main program
- requirements.txt - Project dependencies

## Installation
Install required libraries:

pip install -r requirements.txt

## Run Project
python main.py
